# 顺风拼车平台 —— 项目爆改方案（v1.2）

> 定位：个人求职项目（不上线），简历主攻 **Java 后端开发 + 测试开发** 双线。
> 蓝本：**12306 购票**（座位库存/并发抢购/订单支付链路/微服务架构）× **牛券 oneCoupon**（营销券/结算引擎/压测体系）**综合爆改**，业务壳全新。
> v1.2 修订：**精简过度设计**——删除设备指纹/IP 频控/防黄牛风控/防重放/脱敏/主从/Canal/故障演练等非个人项目必要项，只保留能讲清、能问透的核心考点。

## 一、项目定位与命名

- 业务：**顺风车/拼车出行平台**——车主发布行程（座位库存），乘客搜单、拼车下单、占座、支付、用券；营销券体系；**AI 出行助手**；**天气提醒等体验功能**。
- 命名（候选，可换）：**拼途出行 GoShare** / 顺风同行 / 拼友出行
- 简历叙事骨架：面向大众 C 端的高并发拼车平台，微服务架构 + 营销引擎 + 移动端体验 + 完整测试体系。

## 三、AI 出行助手（意图驱动，用户真会用的功能）

> 不做"问答机器人"，做**意图驱动的出行助手**——用户在顺风车里最常做的事，助手直接帮他办完。

**六大高频场景：**

| # | 用户最想干的 | 助手动作 | 工具（function calling） |
|---|---|---|---|
| 1 | "我拼的车到哪了 / 几点到" | 查实时行程进度（模拟车主位置） | queryTrip |
| 2 | "帮我取消 X 行程 / 改出发时间" | 查订单→确认→执行取消/改签 | queryOrder / cancelOrder |
| 3 | "有什么券能领 / 帮我领张券" | 按路线推荐可领券→一键领取 | queryCoupon / claimCoupon |
| 4 | "发个明天去北京的行程" | 多轮引导补齐信息→预填发单表单 | guidePublish |
| 5 | "明天那边天气怎么样" | 目的地天气 + 出行建议 | queryWeather |
| 6 | 费用/拼车规则/退款/认证怎么算 | FAQ 知识库秒回 | RAG 检索 |

**技术架构（三层漏斗，工程亮点）：**
1. 规则层：高频 FAQ/固定意图走关键词规则，零 token
2. 分类层：意图分类器兜底（含上下文补全）
3. LLM 层：复杂意图才调 LLM + function calling 执行操作；**90% 流量不花 token**
- 会话：WebSocket/SSE 长连接、消息落库、会话状态管理
- 知识库：FAQ 表 + 向量检索（RAG，pgvector/Embedding，复用 ai-doc-lint 经验）
- 兜底：转人工队列
- **质量保障（测开亮点）**：意图 golden 集评估准确率、工具调用成功率、Mock LLM 单测、会话并发压测

## 五、微服务拆分（7 个，控制数量不凑数）

| 服务 | 职责 | 核心组件 |
|---|---|---|
| gateway | 统一入口、鉴权、限流 | Spring Cloud Gateway + Sentinel |
| user-service | 用户/实名/车主认证/信任分 | MySQL、Sa-Token/JWT |
| trip-service | 行程发布、座位库存、ES 搜索、候补队列 | MySQL、Redis、ES、Lua |
| order-service | 下单占座、状态机、超时释放、改签 | MySQL、Redisson、XXL-Job、MQ |
| marketing-service | 券模板/领取/秒杀/核销/结算 | Redis、RocketMQ、ShardingSphere |
| payment-service | 模拟支付、回调幂等、对账 | MySQL 本地消息表 |
| assistant-service | AI 出行助手 + 通知 + 天气提醒 | RocketMQ、WebSocket/SSE、向量库、天气 API |

注册中心 Nacos；分布式事务：**RocketMQ 事务消息 + 本地消息表兜底**（不引入 Seata，柔性事务）；接口文档 Knife4j 聚合到网关；实时通信 WebSocket；对象存储 MinIO。

## 六、技术栈与核心考点（聚焦，不过度设计）

**后端**：JDK 17 + SpringBoot 3.2.x、Spring Cloud Alibaba 2023.0.1.0（Nacos/Gateway/Sentinel）、MyBatis-Plus 3.5.x、MySQL 8、JWT/Sa-Token 鉴权、WebSocket、Knife4j 4.x 接口文档
**中间件**：Redis 7/Redisson、RocketMQ 5.x、ElasticSearch 8.x（IK 分词）、ShardingSphere 5.x、XXL-Job、Skywalking、MinIO
**前端**：Vue3 + Vant（H5）、Vue3 + Element Plus + ECharts（后台）、高德地图 JS API；Vite5 + TS strict + Pinia + Vitest + Playwright
**工程**：Maven 多模块、Docker Compose 本地编排、GitHub Actions CI

**核心考点清单（每项都能问透、答深）：**
- 分布式 ID：雪花算法（订单/券号）
- 缓存治理：Caffeine + Redis 多级缓存、穿透/击穿/雪崩防护、缓存预热
- 消息可靠：RocketMQ 事务消息、消费幂等（去重表）、延时消息（超时释放/发车提醒/天气提醒）、死信重试
- 并发正确性：Lua 原子扣减、Redisson 分布式锁（看门狗）、Sentinel 限流/熔断/降级
- 数据：ShardingSphere 分库分表（订单/券）、ES 数据同步（双写/MQ 方式）、索引优化
- 事务：RocketMQ 事务消息 + 本地消息表兜底（柔性事务，不引入 Seata）
- 接口幂等：业务级幂等（下单、支付回调、领券），去重表 + 唯一索引 + 状态机校验
- 定时：XXL-Job（超时释放座位、天气巡检、券过期）
- 可观测：Skywalking 链路追踪
- 接口文档：Knife4j 聚合网关，在线调试
- 实时通信：WebSocket（乘客-司机消息、行程状态推送）
- 文件存储：MinIO（头像、驾驶证、行程分享图）
- 安全（基础规范级，不作为亮点）：JWT 登录态、参数校验、XSS/SQL 注入基础防护

**明确不做（个人项目无必要）**：设备指纹、IP 频控、防黄牛风控、接口防重放、敏感数据脱敏、MySQL 主从、Canal binlog 同步、故障演练、Seata（同级别普遍不用，改柔性事务）、Prometheus/Grafana（监控仅保留 Skywalking）。

## 八、差异化亮点（和跟做者拉开）

1. **业务壳全新**：顺风车场景，讲"我做了拼车平台"而非"我做了 12306"
2. **双蓝本融合**：座位库存高并发（12306） + 营销券引擎（牛券）协同，两条链路可深度追问
3. **AI 出行助手**：意图驱动 + function calling 直接办成事，90% 流量零 token；配 LLM 评估集
4. **前端亮点**：秒杀动效、地图选点、券包拟物、数据大屏、性能优化，非普通 CRUD 前端
5. **体验功能**：天气提醒、候补递补、安全分享——用户感知强，面试好演示
6. **测试即产品**：单测/集成/接口/E2E/压测/LLM 评估全体系 + CI 门禁

## 九、开发路线（约 6-8 周，7 阶段，每阶段停在干净节点）

- **阶段 0（0.5 周）**：Docker Compose 环境（MySQL/Redis/RocketMQ/ES/Nacos/监控）+ 多模块骨架 + Git 初始化（中文提交）
- **阶段 1（1.5 周）**：单体先跑通核心链路——用户/行程/下单占座/模拟支付（先不做券）
- **阶段 2（1.5 周）**：营销券链路——模板/发放/秒杀/核销/结算引擎 + 单元测试
- **阶段 3（1.5 周）**：微服务拆分 + Gateway/Sentinel + 分库分表 + ES 搜索 + 候补队列（一致性走事务消息+本地消息表）
- **阶段 4（1 周）**：高并发收口——限流、延时释放、消费幂等、JMeter 压测出报告
- **阶段 5（1 周）**：AI 出行助手（六大工具 + 三层漏斗 + 评估集）+ 通知 + **天气提醒**
- **阶段 6（1 周）**：前端亮点（H5 动效/地图/券包 + 后台大屏）+ 信任分/安全
- **阶段 7（0.5 周）**：测试收口（E2E/LLM 评估/覆盖率）+ README/架构文档 + 简历素材
